# My Reading Shelf 📚

## Theme
Personal Reading Shelf Tracker

## Purpose
A web application to help users organize and track their personal book collections.

## Features
- Add, Edit and Delete books from reading list
- Filter books by Category and Status
- Search books by title or author
- Discover bestseller books by category
- Contact form with validation
- Login modal with authentication
- Responsive design using Bootstrap

## Pages
- Home (index.html)
- App - Reading List (app.html)
- Discover Books (discover.html)
- Contact (contact.html)

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Target Audience
Book lovers who want to organize their reading habits.
